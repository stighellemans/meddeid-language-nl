# Netherlands lookup data sources

These runtime lookup files are the Netherlands-specific resources distributed
with DEDUCE 3.0.6. They cover Dutch given names, family names, name particles
and titles, BAG-derived streets, residences, hospitals, and healthcare
institutions. They are kept profile-scoped so `nl-NL` never silently consumes
Belgian address or institution data.

Source: Vincent Menger et al., DEDUCE, release 3.0.6,
<https://github.com/vmenger/deduce>. The upstream `pyproject.toml` declares
`LGPL-3.0-or-later`, while the upstream `LICENSE.md` contains the GPL-3.0 text.
The exact upstream license file is included here as `DEDUCE-LICENSE.md` and
these files must not be published until that metadata discrepancy has been
resolved or the release is reviewed under the more restrictive GPL terms.

For the method, cite Menger, V.J., Scheepers, F., van Wijk, L.M., Spruit, M.
(2017), “DEDUCE: A pattern matching method for automatic de-identification of
Dutch medical text,” *Telematics and Informatics*.
